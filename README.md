# 视频按剧本顺序重命名工具

给 AI 生成的短视频批量改名：把提示词剧本和一堆乱序视频交给它，它会**逐个识别视频里说的台词**，自动和剧本里的镜头对应起来，按剧本顺序重命名视频文件。

## 解决什么问题

用 AI（Seedance 等）批量生成短剧视频时，产出的文件名是乱序的（一段随机字符串），而剧本中每个镜头（P1、P2、剧情1、剧情2……）对应哪条视频，只能靠人耳听台词一个个对。集数多了以后极其耗时。

本工具把这件事自动化：**听台词 → 对剧本 → 改文件名**。

## 功能特性

- **本地语音识别**：内置 faster-whisper，无需联网、无需上传视频，识别结果自动转简体
- **镜头标识自定义**：支持 P、剧情、小节、分镜等任意前缀，选剧本后自动检测
- **模糊匹配**：容忍识别错字漏字（例如识别成"四丫头"也能匹配剧本里的"死丫头"），按相似度取最可能的镜头
- **人工兜底**：匹配度低的高亮提示"请确认"；听不出台词的标记"无台词"，均可手动指定
- **同镜头多视频**：自动加（1）（2）（3）后缀
- **新文件名可编辑**：确认前每行的新名字都可以改
- **一键回滚**：改名记录写入 `rename_log.json`，可全部撤销恢复原名
- **改名落盘校验**：改名后校验磁盘真实生效，防止被杀毒/同步盘回滚导致"假成功"
- **顺手的小细节**：记住上次路径、地址栏直接粘贴路径跳转、点击 ▶ 用系统默认播放器打开视频

## 安装（Windows）

1. 安装 [Python 3.8+](https://www.python.org/downloads/)（安装时勾选 Add to PATH）
2. 下载本仓库（Code → Download ZIP）并解压
3. 在解压目录打开命令行，执行：

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

首次运行会自动下载语音识别模型（约 460MB，存放在 `C:\Users\<你>\.cache\huggingface\`，仅需一次；已配置 hf-mirror 镜像加速）。

## 使用方法

1. 双击 `一键运行.bat`，浏览器自动打开操作界面（http://127.0.0.1:17888）
2. 选择**剧本文件**（.md / .txt）和**视频文件夹**（支持 mp4/mov/mkv 等常见格式）
3. 核对自动检测的镜头前缀（如 P、剧情），不对可手动改
4. 点**开始识别**，进度条实时显示
5. 核对匹配结果：改错的镜头下拉换，听不出的手动指定，新文件名可编辑
6. 点**确认重命名**完成；不满意可点**撤销全部改名**一键恢复

> 台词识别精度与视频音质相关，中文建议视频含清晰人声。识别较慢时可保持默认 small 模型；追求精度可在 `app.py` 中把模型换为 `medium`。

## 剧本格式

台词通常写在引号里，或以 `人名：台词` 形式出现，两种都支持；优先提取"说（情绪）"后面的引号内容。例如：

```markdown
## P01
苏瑶冷笑一声说："你还当自己黄花大闺女？"
周明远："对不起，都是我的错。"
```

## 技术栈

Python + Flask（Web 界面） + faster-whisper（语音识别） + rapidfuzz（模糊匹配）
